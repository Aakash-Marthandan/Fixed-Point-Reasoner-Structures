## 4. Early signals at 2k steps (NOT evidence — the night reads each at 30k / 40k with real fits)
- **D0's curves:** loss 4.99 → 0.85, `ce_in` 2.74 → 0.69, `fpa_ce` 2.25 → 0.15, `train_exact` ≈ 1.5 %, `halt_frac` 0 → .5, mean ACT steps 12.6 of 16. - **The decoder class is visible at 2k on the same corpus and protocol.** The DEC-ARC commits 100 % of cells at step 1 (conf 1.0, converged at step 0–2, one distinct answer, flips 0) — the DEC / field-loop signature; N0 at 2k commits 35–52 % at step 1 (conf .74–.85, 3.5–8 distinct endpoints of k, converged 68–96 %) — the natives' soft signature. On Sudoku the loop set the class (every DEC and field-loop cell 91–98 % at step 1, natives 3–13 %); D15 recorded that the DOMAIN moves the natives (78 % at d64/50k on ARC). At 2k on ARC the DEC-ARC is already at 100 % while the native is at 35–52 %: on the DEC cell the class looks domain-independent, on the natives it grows with training. Eight tasks, 2k steps: a glimpse for the night's D15 row, not a finding.
- **RI condensation at 2k:** every latent draw (σ 1) converges to the cold endpoint (`n_distinct` 1.0, res_z .0013) — init-invariance is present from 2k; whether coverage ever appears (the note's third acceptance instrument; R-DA-4's CLEAN-NO-COVERAGE vs CLEAN+COVERAGE) is the 30k read.
- **Retention is conditioned on the code.** In training `fpa_ce` .15 (trained code rows) while at test the ε = 0 handed-truth start decays to 0 % retention on every query (3-step-fit codes ≈ the table mean). The FPA basin exists for the task's own code, not for an unfitted one — so R-DA-5 depends on the fit protocol's code quality, which argues against cutting the fit below ≈ 150 steps and for the note's first acceptance instrument in its direct form: retention on held-out pairs of TRAINED tasks with their trained code rows (the n_val 96 monitor population, no fit). That row is a small build (`eval_decarc --set mon96` reading the table rows) and is recommended for the night if the calendar allows; otherwise the physics pass reads retention against `sel_step`.
- N0 retains the handed truth 21–50 % at 2k (its anchor_p .3 training) — the natives' basin instrument reads early; the DEC-ARC's 0 % here is at unfitted codes. The night compares both cells at matched code quality (the same fit protocol), which is the reading the paper needs.
