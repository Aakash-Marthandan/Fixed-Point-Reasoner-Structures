## 7. Lessons register (one line each; every one cost a bite; details in the ledger's CONSOLIDATED OPS RECORDS and the per-campaign blocks in git, §8)
- **Billing/backstops:** guest shutdown (DMS) does NOT stop TPU billing — only node deletion does; the node-side delete guard (`plant_guard.sh`, zone-discovering) is the Mac-independent backstop; the launchd watchdog hard-deletes past `runs/tpu_deadline.txt`; teardown verification = a POSITIVE `describe` (a network outage once faked "already gone" → ≤2h idle node); keep-awake (caffeinate) must outlive the supervisor whenever any watch runs (a 7h Mac sleep once blinded a wait).
- **Ssh/remote:** `--ssh-flag "-o StrictHostKeyChecking=no" --ssh-flag "-o UserKnownHostsFile=/dev/null"` (reused-IP 255 class); bound every remote call (`perl -e 'alarm N; exec @ARGV' --`); stderr visible; verify by ARTIFACT (GCS object / node log / describe), never wrapper pgrep (the "LAUNCHED" illusion); canary verifies by artifact on ssh timeout (a passed fit read FAILED through a hung channel); `nohup` over ssh hangs the session — ship remote work via the dispatcher's detach path; `mkdir` before `scp`; a payload containing a pkill pattern kills its own session (two-call pattern).
- **Data/pulls:** `gcloud storage cp` per object + crc32c against `gcloud storage ls -L` (gsutil -m stalls; serial `gsutil cp` stalled at full size with a wrong hash); tarballs of two-stage arms must include the stage-A dir + `config.json`; resumes re-split the rng (valid draw, labeled) and a death within ~3k steps of a resume is "resume-adjacent" (C1, P5) — record resume steps.
- **Chains (sportC1 analysis, 2026-09-03):** a two-stage arm's STAGE-A dir must be restored on a node change or the both-stage val-selection silently degrades to stage-B-only (B0/B1's post-preemption scans + vsel censuses ran on memorized stage-B grids while their fulls/screens ran on the right A:20k grids — the analyzer's gates did not check grid consistency across an arm's evals); fixed in `chain_sportC1.sh` (`ensure_local_pretrain` restores `${arm}a_pretrain.tgz`; harness S8) — EVERY resume path needs its own harness scenario, and the analyzer asserts one ckpt path per (arm, vsel).
- **Chains:** one-shot amputation truncates `metrics.jsonl` to the last finite grid (death step bounded by the grid census) and the trainer keeps running on NaNs (early-NaN abort owed); fixed-step screens beyond a death are garbage (243 violations) — skip; completion guard: sentinel/final only when every artifact is present (a vacuous sentinel once tore a pod down mid-campaign); merges n-gated and idempotent; `--merge` on a busy node needs `JAX_PLATFORMS=cpu`; multi-host DP needs per-host confinement (93a79d4); v6e-16 = 4×4 not 2×8; T12 at d16 needs `--remat`; the relaunch counter resets on healthy polls (a monotone counter once nearly tore down a healthy campaign at a wall recycle); static worker maps beat claim systems (claim races/TTL takeovers were the rung-2 incident class).
- **Local tooling:** exit-status masking through `| tail`/`| grep` bit ≥4 times; `grep -c` already prints 0 (`|| echo 0` fabricates); zsh does not word-split unquoted vars; macOS has no `timeout(1)`; `/bin/bash` is 3.2 (no associative arrays); a Monitor/watcher whose command text contains a `pgrep -f` pattern self-matches and can deadlock the waiter (bracket the pattern).
- **Spot weather:** us-east1-d churns in US-day hours (maintenance kills with zero progress happen); night windows land in minutes; Mumbai asia-south1-c is a reliable v6e-16 source (2.35× cost) — fallback only; QR flex-start waited ≥7h ungranted; quota buckets are zonal and `Unlimited` rows are decoration — only creates tell the truth.
